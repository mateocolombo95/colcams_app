# Product decisions

## 2026-10 — Initial decisions

- Build as a web app.
- Develop locally in VS Code.
- Keep code in a private GitHub repository.
- Use Next.js + TypeScript for frontend.
- Use FastAPI + Python for backend.
- Use MongoDB because it matches the team's existing knowledge and the evolving document-oriented domain.
- Start with CCTV IP.
- Model the main aggregate as a Project rather than only a Quote.
- Keep engineering rules deterministic.
- Add AI later as an interface/assistant layer.
- Add map/site-plan support after the quote engine and supplier catalog are proven.
